# DeepSeek 桌面宠物（DSH 动态插件）

在 DSH 网页端右下角显示一只可拖动的桌面宠物，随工作状态切换形态，审批/完成时语音提醒。
所有页面的宠物都会收到全局提醒（任何对话/项目的事件都会广播）。

## 形态与语音搭配

| 状态 | 触发 | 图片 | 声音 |
| --- | --- | --- | --- |
| 😴 空闲 | 没有任何任务 | 蓝色鲸鱼女仆（用户素材）或 鲸鱼吹泡泡，随机（点一下宠物可手动切换） | 无（泡泡动画） |
| 💦 工作 | 有 agent/任务/工作流在跑 | 鲸鱼喷水图 | 无 |
| ❗ 审批 | 有审批待处理 | 蓝鲸女仆敲门动画（4 帧循环） | 🔊 地精「时间就是金钱，我的朋友」 |
| 🎉 任务完成 | 任何项目/后台任务结束 | 画面保持当前状态 | 🔊 鱼人叫（原始一声） |

- 审批被处理完 → **立即**回到工作/空闲状态
- 声音事件广播给**所有挂载的宠物实例**（每个打开的对话页面都会响）
- 空闲形象只在**进入空闲**时随机一次，不自动切换；不满意时点一下宠物就在女仆/鲸鱼间切换

## 预览页

插件运行后打开 `http://127.0.0.1:3080/pet-preview`：
- ① 状态 → 图片 → 声音 搭配表（可一键演示）
- ② 全部素材一览
- ③ 声音试听

## 配置

- 素材目录通过环境变量 `DSH_PET_ASSETS` 指定；未设置时使用默认路径（当前机器为 `pet-assets` 所在目录）。
  其他机器请先 `export DSH_PET_ASSETS=/你的/素材目录` 再加载插件。

## 安装 / 加载（DSH 动态插件）

1. 准备素材目录（上面的 `pet-assets/` 结构）。
2. 在 DSH 中加载插件：把本插件源码（Host 半 + Client 半）通过 DSH 插件机制 define + run。
   - 或按项目的 `plugin/` 目录里的源码文件手动注册。
3. 每个想看到宠物的对话标签页：`设置 → 插件 → DeepSeek 桌面宠物 → 运行`。
4. 刷新页面后宠物会消失（页面内存特性），重新点「运行」即可。

## 兼容性

- 审批检测依赖 DSH 的会话日志事件 `approval/asked` / `approval/decided`。
- 不同 DSH 版本事件名可能不同 —— 若不工作，检查 `session/event` 中审批事件的实际名称并调整。

## 源码（分享用）

插件源码已从 DSH 会话导出到仓库：

- `plugin/host.js` —— 插件 Host 半（进程内：状态机、事件监听、RPC、预览页路由）
- `plugin/client.js` —— 插件 Client 半（浏览器：画面渲染、拖动、音效播放）

**加载方式**：在 DSH 中通过插件机制 define + run 这两个文件（Host/Client 分别注册）；或参考「安装 / 加载」一节。
**素材路径**：通过环境变量 `DSH_PET_ASSETS` 指定（默认相对当前工作目录的 `pet-assets/`），分享前无需改代码。

## 音效版权说明（重要）

**这个项目是干什么的**：在 DSH 网页上养一只桌面宠物，核心用途是**提醒用户及时处理审批、并在项目结束后提示去查看后续进展**——避免因为漏看而让项目一直卡着。

**为什么选这两个音效（也是一种致敬）**：

- 🔊 地精「时间就是金钱，我的朋友」—— 审批出现时响起，非常贴合"该去处理了，别耽误"的提醒语境；
- 🔊 鱼人叫声 —— 项目完成时响起，自带喜感，让人会心一笑。

这两个音效**来自《魔兽世界》（Blizzard 版权音频）**，不是本项目自有内容，选用它们既是语境契合，也算是对这款游戏的**致敬**：

- 仅供**个人学习 / 非商业使用**；
- 如果版权方（Blizzard）要求删除，请立即移除 `pet-assets/sounds/` 下的对应文件；
- 如要公开发布 / 商用，请替换为自有或免版权（CC0）音效。

## 桌面宠物使用

- 拖动宠物可全屏自由摆放（不限制高度），拖动时朝移动方向转身。
- 首次点击/按住宠物后解锁浏览器音频（自动播放策略）。
- 任务完成/审批时所有页面会响对应声音。
