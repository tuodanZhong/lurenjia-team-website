# dsh-song-memory

> [English](README.md) | **中文**

为 DeepSeek Harness 打造的跨工具记忆中枢：把你的对话整理成**一篇 AI 写好的记忆文章**——你读这一篇，AI 也读这一篇，跨对话、跨工具。

## ✨ 特性
- **一篇记忆，一个真相**：AI 不断把你的一切整理成一篇连贯文章（`memory.md`）。打开记忆页就像读文档，没有碎片列表。
- **自动整理**：对话先进草稿箱，AI 把新内容融入文章（新事实进来、过时内容出去）。攒 5 条或 30 分钟内有新内容就自动整理，也可随时手动整理。
- **记住 AI 干活的成果**：AI 回复里的项目事实（完成了什么、决定用什么、修复了什么）会自动提取进记忆——按句提取、不记思考过程、不记子代理、不记"还没决定"这类话。
- **密钥脱敏**：写入记忆前，`sk-xxx`、`api_key=...`、`password:`、私钥块等常见密钥一律替换为 `[REDACTED]`，项目记忆对公开仓库也安全。
- **跨对话真记忆**：每次对话开始，AI 自动读同一篇文章。
- **跨工具联动**：项目记忆写入标准 `AGENTS.md` 区块，Claude Code（cc）、Codex、Cursor 原生可读。
- **本地透明**：纯 Markdown 文件，无云、无黑盒。
- **简单至上**：一篇文章 + 一个草稿箱 + 项目文件，没有多余的碎片要同步。

## 🚀 安装
```bash
cd ~/dsh-song-memory
dsh plugin --profile web add dsh-song-memory
```

## 📂 存储位置
- **记忆文章**：`~/.song-memory/memory.md`（AI 整理、持续更新的"关于你"的文章——AI 每次对话读的就是它）
- **草稿箱**：`~/.song-memory/notes.md`（等待整理的对话原始记录）
- **项目记忆**：`<对话工作目录>/AGENTS.md` 的 `<!-- song-memory:auto -->` 区块（cc/Codex/Cursor 可直接读取）

## 🛠️ 查看与管理
- **快速查看**：任意对话页顶部标签栏 → **记忆** 标签
- **完整管理**：DSH 设置 → **记忆管理**：阅读记忆文章、点"整理记忆"、开关注入/自动记录、清空记忆

## 🔒 隐私提示
- 插件默认捕获**对话原文**进草稿箱，分享记忆文件截图时请注意内容。
- 项目记忆写入 `<对话工作目录>/AGENTS.md`。**公开项目前请先检查或清空自动记忆区块**，避免聊天片段进入公开历史。
- 注入前记忆会做提示注入特征清洗；不需要时可在设置页完全关闭自动记录。
- 请以默认 `127.0.0.1` 方式运行 DSH。插件的管理接口未做认证，切勿暴露到网络接口上。
