接口契约助手：解析 OpenAPI 3 — a [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh) plugin. Pure Node, zero runtime dependencies.

## 工具 Tools

- `gen_client`
- `diff_spec`

## 安装 Install

```sh
dsh plugin --profile web add dsh-api-contract
# 或任意 profile：dsh plugin --profile <name> add dsh-api-contract
```
