# 合同起草模式

[**English**](README.md) | **中文**

**面向中国大陆法律实务的专业合同起草 Agent 工作模式**，运行在 DeepSeek Harness 上。

---

## 这是什么

这是一个 DeepSeek Harness 的**运行模式**（agent preset）：你用大白话描述交易背景和核心条款，AI 按律师工作流自动完成理解 → 交易条件表 → 缺口分析 → 少量关键提问 → 法律检索 → 合同架构 → 起草 → 五路并行审查 → 修订 → 16 项校验 → 最终交付。

它模拟真实律师使用 AI 起草合同的方式：

> **你决定交易和核心利益分配，AI 负责把这些决定转化为完整、专业、可执行的合同。**

默认法域为中华人民共和国大陆地区；一套领域无关的核心工作流 + 可插拔的**领域包**，覆盖不同类型的合同。

## 它和普通聊天模型有什么区别

- **不"一句话生成合同"**：先理解交易、整理交易条件表、发现你没说但必须想清楚的配套问题，再起草；
- **只问你真正重要的问题**：利润怎么算、亏损谁担、退出要不要补偿——每次给出 A/B/C 方案和立场建议，不轰炸提问；
- **五路 AI 审查**：合法性、条款完整性、对方立场攻击、诉讼视角、前后一致性并行审查后统一修订；
- **不编造**：不知道的公司名、金额、法条一律用「待填写」占位，绝不瞎编；
- **交付四类信息分明**：你决定的 / AI 补充的 / AI 假设的 / 待确认的，附风险备忘与签署前待办清单。

## 安装

```bash
# 将 preset/ 目录复制到 DSH 用户预设目录
cp -R preset ~/.dsh/.agent-presets/dsh-contract-drafting-agent
```

然后在 DSH 中**新建一个会话**，在预设选择器中选择「**合同起草模式**」。

## 使用方法

在对话中直接描述你的交易和核心条款，例如：

> 帮我起草一个合作协议。甲方出资50万元。乙方负责实际运营。利润甲方60%，乙方40%。任何一方退出需要提前30天通知。乙方未经甲方同意不得把业务交给第三方。

AI 会：受理事项 → 生成交易条件表 → 分析条款缺口 → 就少数关键问题让你拍板（A/B/C 方案）→ 检索并核验法律依据 → 起草 → 五路审查 → 修订 → 16 项校验 → 交付合同包（合同正文 / 核心条款说明 / AI 补充条款 / 风险备忘 / 待办清单）。

## 工作产物

每个合同事项保存在工作目录 `matters/<编号>/` 下：交易条件表、核心条款登记、缺口报告、决策记录、审查报告、修订记录、草稿、最终交付包——全程可审查、可追溯、可复用。

```
    ├── 07-drafting               # 起草 Draft v1
    ├── 08-multi-agent-review     # 五路并行审查（附 REVIEWER-PROMPTS.md 模板）
    ├── 09-review-synthesis       # 审查汇总与修订

```

## 常见问题

- **这是法律意见吗？** 不是。输出为工作草稿，不构成正式法律意见；重大交易（投融资、涉诉、跨境）签署前请由执业律师复核。
- **能新增合同领域吗？** 可以。新增一个 `dp-<领域>/SKILL.md` 领域包即可，核心工作流无需改动。
- **支持非大陆法域吗？** 默认法域为大陆地区；涉及港澳台、境外主体、跨境交易或外国法时，受理环节会自动重新识别法域。
