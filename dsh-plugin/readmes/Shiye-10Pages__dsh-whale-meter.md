## 30 秒装上

```bash
dsh plugin --profile <你的profile> add dsh-whale-meter
```

重启 `dsh web`，会话页顶部出现 🐳 花费徽章，点开就是完整账单。

> 从源码装：`dsh plugin --profile <你的profile> add github:Shiye-10Pages/dsh-whale-meter`（首次需按提示在 profile 的 `pnpm-workspace.yaml` 里授权构建，建议锁定 commit）。

## 它能告诉你什么

- **🐳 消耗量段位**：本月烧了多少 token → 🐟小鱼苗 / 🐠热带鱼 / 🐬海豚 / 🐋座头鲸 / 🐳蓝鲸，附估算分位与「≈ 多少遍《三体》」的量级换算。**全部本地计算，零上报**——分布曲线内置在仓库里（[tier.data.ts](src/tier.data.ts) 写明了推导依据，欢迎用真实数据提 PR 改进），分位如实标注为估算，不谎称「全球排名」
- **今日 / 昨日 / 本月 / 累计花费**：按 DeepSeek 官方价目实时估算，¥ 为主（可切 $）
- **📈 涨价对比**：同一份用量，新价 vs 旧价分别多少、多花了多少，直接标在面板上。8-17 之前是预演（「按新价今天要花 ¥X」），之后是回溯（「按旧价只要 ¥X」）
- **⚡ 峰谷计价**：8-17 起分高峰/空闲两档（空闲是高峰的一半）。电表按每笔请求各自发生的时刻套价，处于空闲档时徽章亮 `⚡½`——**注意这不等于比涨价前便宜，空闲价依然高于旧平价**
- **跨调价日正确**：价目表按「生效区间」组织，8-16 的账按旧价、8-17 的账按新价，历史账单不会被一刀切算错
- **缓存账本**：命中率 + 「缓存帮你省下 ¥X」——涨价后缓存比以前更值钱（命中与未命中的差价被同步放大）
- **多厂商精准计价**：DeepSeek / Anthropic / OpenAI / Google / 智谱 GLM / 月之暗面 Kimi 共 **46 个模型**，逐项核对官方定价页。**支持国内厂商的分档计价**（如 GLM-5.1 输入 <32K 走 6 元、≥32K 走 8 元；GLM-4.7 还要再按输出长度细分三档），按每次调用的实际用量选档，不是估个大概
- **补记历史**：装上后自动把插件安装**之前**的会话补进账本（只读遍历 dsh 会话日志），不用从零开始攒数据
- **分模型 / 分会话账单**：谁在烧钱一目了然；失败重试的请求也如实入账（它们同样计费）
- **近 14 天趋势** 与 账户余额（配置 API key 后显示）
- **每日预算线**：超了就提醒
- **🐳 账单分享卡片**：一键生成深海风 PNG——本月花费、等价梗（「≈ 2.3 瓶冰红茶」）、缓存节省，保存或复制直接发

## 配置（可选）

零配置即可用。想调整时，在 profile 的 `cordis.patch.yml` 覆盖：

```yaml
- update:
    - id: whale-meter
      config:
        currency: CNY        # 或 USD
        budgetDaily: 5       # 每日预算（展示币种）
        apiKey: sk-...       # 仅用于查询余额；缺省读 DEEPSEEK_API_KEY 环境变量
        usdToCny: 7.2        # 换算只有美元官方报价的模型（如 OpenAI）时用
        backfill: true       # 回填安装前的历史会话，默认开
        pricingUpdate: false # 拉取最新价目表，默认关（见下）
        prices:              # 自定义/补充价目（每百万 tokens）
          my-model: { hit: 0.5, miss: 4, out: 12, write: 5 }
```

## 价格怎么保持最新

各家厂商都**没有价格 API**，所谓"实时同步"只能靠爬定价网页——页面一改版就挂，而**爬错价格比不更新更糟**：一个记账工具报错数字，用户还以为是真的。所以这里不爬。

价格走两条路：

1. **内置表**（默认）：每条都逐项核对官方定价页，跟着版本发布。准确性优先。
2. **远程表**（可选，`pricingUpdate: true`）：从本仓库拉一份 [`pricing.json`](pricing.json)，每天至多一次。同步的是**经人工核对 + CI 校验**的表，不是爬虫抓的；拉取失败、超时、格式不合法一律静默回退内置表，绝不劣化。

**发现价格变了？** 改 [`src/pricing.data.ts`](src/pricing.data.ts) 一个文件，跑 `npm run gen:pricing`，提 PR——合并后所有开启远程表的用户次日自动生效，不用等发版。附上官方定价页链接就行，这是最受欢迎的一类 PR。

> 想要的模型不在表里？用上面的 `prices` 自己补，或者提个 issue 告诉我。**未知模型不会被瞎算**，面板会如实标为「未定价」。

## 工作原理 & 数据隐私

- 监听 dsh 会话日志中的用量记录（`assistant/chunk usage` 权威、`assistant/message.usage` 兜底，按官方口径去重），逐行追加到本机 `~/.dsh/whale-meter/usage-YYYY-MM.jsonl`
- **只存原始 tokens，不固化金额**——价目表更新后历史账单自动按新表重算
- **所有数据都在你本机**。除了你主动配置 key 后的余额查询（直连 DeepSeek 官方接口），不发出任何网络请求，不上报任何遥测
- 电表坏了不能弄沉船：采集器全程防御式编程，任何异常只降级不打扰 agent 运行

## FAQ

**Q：金额和平台账单会完全一致吗？**
按官方价目和逐笔时刻估算，通常非常接近；以 [DeepSeek 平台账单](https://platform.deepseek.com) 为准。价目表内置版本号（当前 `2026-08-16`，已收录 8-17 新价），官方调价后只需改 `src/pricing.data.ts` 一个文件——里面是按「生效区间」组织的价格时代，追加一组即可，历史账单自动各按各价重算。

**Q：8-17 到底涨了多少？**

| v4-flash（每百万 tokens） | 命中 | 未命中 | 输出 |
|---|---|---|---|
| 8-17 前 | ¥0.02 | ¥1 | ¥2 |
| 8-17 起・高峰 | ¥0.10 | ¥3 | ¥9 |
| 8-17 起・空闲 | ¥0.05 | ¥1.5 | ¥4.5 |

v4-pro 同步调整（高峰 ¥0.30 / ¥9 / ¥27，空闲减半）。高峰时段为北京时间 9:00-12:00、14:00-18:00。
换句话说：**即使全跑在空闲时段，也比 8-17 之前贵**。电表能做的是让你看清这件事，以及把重活挪到空闲档少挨一刀。

**Q：用了第三方模型（非 DeepSeek）怎么办？**
tokens 照常统计；未知模型**不会编造价格**，标记为「未定价」，可在 `prices` 里自行补价目。

**Q：支持 TUI / headless 吗？**
数据采集在 host 侧，Web 面板是展示层。TUI 场景可直接 `curl http://127.0.0.1:3080/whale-meter/api/summary`。独立 TUI 视图在路线图上。
